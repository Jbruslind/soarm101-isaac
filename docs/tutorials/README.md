# Tutorials

Planned tutorial series. Each will be a runnable script plus a short page. Tracked in [I-12](https://github.com/Jbruslind/soarm101-isaac/issues/12).

1. **Isaac 6.x setup** (planned): Install and run Isaac Sim 6.1 / Isaac Lab 3.0 in the container. See [I-12](https://github.com/Jbruslind/soarm101-isaac/issues/12).
2. **Load a scanned room** (planned): Load a scan-twin export as an Isaac scene and place the arm in it. See [I-12](https://github.com/Jbruslind/soarm101-isaac/issues/12).
3. **Add a calibrated D455** (planned): Add a simulated D455 built from the measured intrinsics. See [I-12](https://github.com/Jbruslind/soarm101-isaac/issues/12).
4. **Noisy depth and how it's validated** (planned): Apply the D455 noise model and see how it is checked against real data. See [I-12](https://github.com/Jbruslind/soarm101-isaac/issues/12).
5. **Record in sim and reconstruct with scan-twin** (planned): Write a TUM recording with ground truth in sim and reconstruct it with scan-twin. See [I-12](https://github.com/Jbruslind/soarm101-isaac/issues/12).
6. **Collect LeRobot data in your own room** (planned): Collect LeRobot episodes in a scene of your own room. See [I-12](https://github.com/Jbruslind/soarm101-isaac/issues/12).
